Laboratory Challenge: Student Academic Grade Computation System

Lab Time Left
--:--:--

Problem Scenario

You are tasked to develop a Student Academic Grade Computation System using Java on your laboratory computer. The program will accept a student's information and performance scores based on the institution's grading performance scale. Your program must calculate the weighted grade of a student based on the following grading components and determine the student's final performance remark using logical statements:

Grading Component Percentage Weight
Major Exams (Prelim, Midterm, Prefinal, Final) 30%
Project 30%
Quizzes & Assignments 30%
Attendance 10%
Total 100%

Laboratory Requirements

Task 1 – Student Information 5 points

Ask the user to input the following information using appropriate Java data types:

  • Student Name
  • Student ID Number
  • Course and Section
Task 2 – Input Grades 10 points

Ask the user to input percentage scores (scale of 0 to 100) for:

  • Major Exams (Prelim, Midterm, Prefinal, Final)
  • Project
  • Quizzes & Assignments
  • Attendance
Task 3 – Mathematical Operations and Weighted Grade Computation 15 points

Calculate the weighted grade using the exact formula below:

Final Grade = (Major Exams × 0.30)
            + (Project × 0.30)
            + (Quizzes & Assignments × 0.30)
            + (Attendance × 0.10)
Task 4 – Logical Statements & Remarks 10 points

Using if, if-else, or if-else if, determine the performance remark:

Final Grade Performance Remark
90–100Excellent
85–89.99Very Good
80–84.99Good
75–79.99Passed
Below 75Failed
Task 5 – Display Student Grade Report 10 points

Display the complete student grade report containing:

  • Student Name, Student ID Number, Course and Section
  • Major Exams Score and Weighted Contribution
  • Project Score and Weighted Contribution
  • Quizzes & Assignments Score and Weighted Contribution
  • Attendance Score and Weighted Contribution
  • Final Computed Grade & Performance Remark
